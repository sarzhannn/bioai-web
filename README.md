# BioAI — инструкция по запуску как настоящего бесплатного сайта

Эта версия использует **Google Gemini API** вместо Anthropic — у него есть
по-настоящему бесплатный тариф, не требующий привязки банковской карты.
Твой ключ хранится только на сервере (в папке `api/`), браузер посетителя
его никогда не видит.

## Шаг 1 — получить бесплатный ключ Google Gemini

1. Зайди на https://aistudio.google.com/apikey
2. Войди через любой Google-аккаунт
3. Нажми "Create API key"
4. Скопируй ключ (начинается с `AIza...`)

Карта не нужна. Бесплатный тариф даёт ограниченное число запросов в минуту
и в день — для демонстрации проекта на защите и обычного тестирования этого
с большим запасом достаточно. Если вдруг упрёшься в лимит (увидишь ошибку
429 в ответе), в файлах `api/analyze.js` и `api/review.js` смени модель
`gemini-2.5-flash` на `gemini-2.5-flash-lite` — она ещё легче по лимитам.

**Никому не показывай этот ключ и не выкладывай его в открытый код на GitHub.**

## Шаг 2 — проверить локально (по желанию)

```bash
npm install -g vercel
cd bioai-web
npm install
cp .env.example .env       # вставь туда свой реальный GEMINI_API_KEY
vercel dev
```

Откроется адрес вроде `http://localhost:3000`, где уже всё работает,
включая ИИ-анализ и проверку источников.

(Обычный `npm run dev` через Vite не запустит серверные функции из папки
`api/` — для них обязательно нужен `vercel dev`.)

## Шаг 3 — выложить на GitHub

```bash
cd bioai-web
git init
git add .
git commit -m "BioAI first version"
git branch -M main
git remote add origin https://github.com/ТВОЙ_НИК/bioai-web.git
git push -u origin main
```

Файл `.env` в GitHub не попадёт — он исключён в `.gitignore`, это правильно
и безопасно: ключ никогда не должен попадать в открытый репозиторий.

## Шаг 4 — задеплоить на Vercel (получить настоящую ссылку)

1. Зайди на https://vercel.com и войди через свой GitHub-аккаунт
2. "Add New..." → "Project" → выбери репозиторий `bioai-web`
3. Перед деплоем открой "Environment Variables" и добавь:
   - Name: `GEMINI_API_KEY`
   - Value: свой ключ из Шага 1
4. Нажми "Deploy"

Через минуту-две получишь настоящую бесплатную ссылку вида:

```
https://bioai-web-твойник.vercel.app
```

Полноценно работающий сайт — можно отправлять кому угодно, открывать
с телефона, показывать на защите проекта. Хостинг на Vercel тоже
бесплатный для такого объёма трафика.

## Важно понимать про эту версию

- **Хранение данных пользователя** (история, добавленные в базу записи)
  хранится в `localStorage` браузера — у каждого посетителя своя локальная
  копия. С другого устройства будет видна только встроенная база. Для
  школьного/студенческого проекта этого достаточно.
- **Бесплатный тариф Gemini** имеет лимиты по скорости (запросов в минуту)
  и по количеству в день — при обычном использовании (ты + несколько
  человек на защите тестируют по очереди) в лимиты не упрёшься.
- Качество ответов Gemini Flash в целом сопоставимо для такой задачи,
  но чуть менее "рассуждающее", чем топовые платные модели — для
  предварительной оценки болезней растений/животных этого более чем
  достаточно.
- Если по какой-то причине захочешь вернуться на Anthropic — понадобится
  просто заменить содержимое `api/analyze.js` и `api/review.js` на версию,
  которая обращается к `api.anthropic.com` вместо
  `generativelanguage.googleapis.com`, и подставить свой платный ключ —
  структура остального проекта не поменяется.
